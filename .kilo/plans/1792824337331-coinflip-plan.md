# Coin Flip Gambling Game Plan

## Status
The coin flip gambling game is already implemented in this repository.

## Affected Files
- `src/economy/games/coinflip.js` — core `play(userId, bet, guess)` logic
- `src/commands/coinflip.js` — slash + prefix command
- `coinflip.test.js` — test suite (spec)

## Behavior (matches tests)
- Random outcome: `Math.random() < 0.5 ? "Heads" : "Tails"`
- Win payout: balance += bet * 2.5, profit = bet * 1.5 (net profit bet*1.5, total returned bet*2.5)
- Loss: balance -= bet, profit = -bet
- Validations: gambling enabled, integer positive bet, min/max bet, sufficient funds, cooldown, valid guess (Heads/Tails/h/t, case-insensitive)
- Cooldown enforced via `lastFlipAt`
